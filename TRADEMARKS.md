# Trademarks

The CrispCAD kernel lab is a renamed fork of kernelCAD. kernelCAD's MIT licence
covers its source code, not the kernelCAD name or logo. Its trademark policy (as
of the fork point, preserved below) requires forks to be renamed and not to
suggest endorsement. The lab therefore:

- uses its own names: the repository `crispcad-kernel-lab`, the package
  `crispcad`, the `crispcad-lab` CLI, the MCP server, the documentation and
  exported-file metadata (`CrispCAD kernel lab <version>`);
- names kernelCAD only to say truthfully where the code comes from, and in the
  `.kcad.ts` file extension, which is kept so existing model files stay
  compatible;
- does not use the kernelCAD logo.

Retained copyright notices in source files are not trademark use.

## kernelCAD trademark policy (as of the fork point)

### kernelCAD Trademark Policy

The MIT license covers the kernelCAD **source code**. It does not grant any
rights to the **kernelCAD name or logo**, which identify this project and its
maintainers.

## You may, without asking

- State truthfully that your software uses, supports, or is built on kernelCAD.
- Use the name in articles, talks, tutorials, benchmarks, and package
  metadata to refer to this project.
- Distribute unmodified copies of kernelCAD under the kernelCAD name.

## You may not, without written permission

- Use "kernelCAD" (or a confusingly similar name) as the name of a modified
  version, fork, product, service, company, or domain name.
- Use the name or logo in a way that suggests your product or service is
  made, endorsed, or maintained by the kernelCAD project.

Forks must be renamed. Keeping the required MIT copyright notice in source
files is expected and is not a trademark use.

## Attribution in output

kernelCAD writes "kernelCAD <version> (https://kernelcad.com)" into exported
file metadata and shows a "Made with kernelCAD" link on public viewer pages
(see [ATTRIBUTION.md](ATTRIBUTION.md)). A renamed fork may keep this
attribution: it truthfully states that the software is built on kernelCAD. It
may also change or remove it in `src/shared/links/attribution.ts`. It may not
change it to suggest that its own product is kernelCAD or is endorsed by the
kernelCAD project.
