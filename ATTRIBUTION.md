# Attribution in output

CrispCAD names itself in the files it writes. Geometry is never changed.

| Format | Where | Value |
| --- | --- | --- |
| STEP | `FILE_NAME` originating_system | `CrispCAD <version> (https://github.com/CrispStrobe/kernelCAD-web)` |
| GLB | `asset.generator` | same |
| STL (binary) | 80-byte header | same, plus the export date |
| DXF | first `999` header comment | same, plus the export date |
| URDF, SRDF, SDF, MJCF | XML comment | `<!-- Generated by CrispCAD <version> (…) -->` |
| PDF/SVG drawings | title block | "Made with CrispCAD · github.com" |

`src/shared/links/attribution.ts` holds the name and links. CrispCAD has no hosted
app or share pages.

### Boolean keep-parts idea

`shape.split` keeps the overlap and both leftovers as separate solids. That
framing — retain each boolean fragment instead of discarding the complement —
follows the idea in [Cadrs](https://github.com/Sh1Art/Cadrs) (MIT and
Apache-2.0). kernelCAD does not include Cadrs source. The split uses the
already-bound Open CASCADE cut and common operations.
